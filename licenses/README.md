# Additional runtime license texts

These are unmodified upstream notices retained for the frozen Windows bundle.
They supplement the per-package license files collected from installed wheel
metadata and Python's bundled LICENSE.txt. No model checkpoint is redistributed.

- Tcl 9.0.4: https://github.com/tcltk/tcl/blob/core-9-0-4/license.terms
- Tk 9.0.4: https://github.com/tcltk/tk/blob/core-9-0-4/license.terms
- OpenSSL 3.5.7: https://github.com/openssl/openssl/blob/openssl-3.5.7/LICENSE.txt

Versions correspond to the Python 3.14.7 / Tk 9.0.4 build used locally. A different
runtime build must retain the notices for its actual bundled component versions.
